# META: структурная проверка оценивания

Дата: 13 октября 2026. Этот отчёт уточняет предыдущий TASK_LINK_FIX.md.

## Первопричина и область влияния

В `services/lesson_validation.py`, `normalize_meta_lesson`, после установления связи задания через `task_id` продолжала вызываться `_check_relevance`. Она требовала пересечения основ слов критерия/дескриптора со словами задания и этапа. Поэтому допустимое «Аргументирует выводы с примерами» могло отклоняться: структурная принадлежность уже была установлена, но лексическая проверка её перечёркивала.

В `services/meta_tasks.py`, `resolve_assessment_task`, оставался отдельный запасной поиск принадлежности по словам и формулировкам. Он мог пропускать связь при перефразировке или создавать восстановленные задания из текстовых свидетельств. Обе зависимости от лексики удалены из условий успешной валидации. Нормализация слов осталась только для предотвращения повторения уже объявленной инструкции в отображаемом содержании этапа.

Проверки оценивания применяются только к META. Тестами подтверждены отдельные ветки генерации, DOCX и сохранения ETEC, ALT, Q, ATKK: META-валидатор там не вызывается.

Реальный JSON двух ручных генераций не предоставлен. Найденная причина новой ошибки подтверждается кодом прежней проверки; конкретную структуру старого AI-ответа установить нельзя. Новые RU/KK примеры iOS и пример Navigation — синтетические регрессии на основе сообщённых условий, а не записи реальных запросов.

## Изменённые функции

- `services/lesson_validation.py`: `LessonValidationError` добавляет диагностические code/task_id/phase; `normalize_meta_lesson` и `_normalize_meta_lesson` проверяют структурные ссылки, уникальность оценивания, баллы и время. `_belongs_to_task` проверяет вложенные ссылки критерия и дескриптора. `_descriptor` принимает строки прежней схемы и новые объекты. `_check_relevance`, `_topic_stems` и их словари удалены.
- `services/meta_tasks.py`: `declared_tasks` строит реестр настоящих заданий из этапов; `resolve_assessment_task` проверяет существование ID и принадлежность этапу. Лексическое сопоставление и создание заданий из строки оценивания удалены.
- `services/ai.py`: `create_lesson` запрашивает согласованные tasks/id, assessment/task_id и descriptor/task_id/text/action/result/points, разрешает перефразировки и фиксирует отказ нормализации. Один вызов провайдера, без автоматической повторной генерации.
- `services/lesson_plan_service.py`: `save_generated_lesson_plan` сохраняет прежний порядок: нормализация → DOCX в памяти → единственный атомарный save. Добавлена фиксация отказа на этапах normalization/docx/save.
- `services/meta_diagnostics.py`: новые `validation_error`, `failure_metadata`, `anonymized_snapshot`, `record_meta_failure` фиксируют безопасную структурную диагностику.
- `config/diagnostics.py`: новая `meta_diagnostic_directory` разрешает снимки только при явной локальной настройке.
- `app.py`: `_log_create_failure` пишет тип/код/этап и хеш ссылки, без текста исключения, предмета, темы и полного traceback с потенциальными данными.

`services/docx_generator.py`, `build_doc`, уже повторно нормализует META перед экспортом; изменение схемы совместимо с таблицей Word через текстовые descriptors и descriptor_points. Новые descriptor_details сохраняют структурные поля при повторной проверке.

## Правила

Неизвестный task_id, противоречащий stage_key, повторный task_id источника или повторное оценивание отклоняются. Явная вложенная ссылка критерия/дескриптора обязана совпадать с ID строки. При отсутствии вложенной ссылки она наследуется от проверенной строки.

Безопасное восстановление ограничено: tasks как одиночный объект/словарь ID, известные алиасы полей, отсутствующий stage_key по существующему task_id, отсутствующий task_id при единственном объявленном задании указанного этапа, пропущенная детализация баллов. Задания из оценивания не создаются. Противоречивые явные ссылки и числа не исправляются.

Дескриптор имеет непустой текст и поле наблюдаемого действия action; для прежней строки action сохраняет её исходный текст. Явно пустое action отклоняется. result обязателен при requires_result=true; явно заданный result непустой. Валидация не пытается доказать педагогическую семантику свободного текста с помощью списка глаголов или ключевых слов: требования к наблюдаемому действию и измеримому результату заданы также в промпте. Структурно связанная перефразировка допускается.

Сумма заданий строго 100; сумма дескрипторов равна баллу задания. Неверная явно указанная сумма отклоняется, а не масштабируется. Продолжительность этапов детерминированно приводится к 70 минутам с сохранением пропорций и минимумом одной минуты на этап; результат повторно проверяется при DOCX.

## Локальная диагностика

Для локальной разработки задать `LESSONAI_ENV=development` и `LESSONAI_META_DIAGNOSTICS=1`. Необязательный `LESSONAI_META_DIAGNOSTIC_DIR` задаёт каталог; по умолчанию `/private/tmp/lessonai-meta-diagnostics`.

По умолчанию отключено; production не разрешает снимки даже при включённом флаге. Сохраняется не более 20 файлов с правами 0600 в каталоге 0700. Все свободные тексты и метаданные удаляются; реальные ID заменяются task_001 и т. п. Сохраняются структурные связи, числа, тип/код ошибки и этап отказа. Ни ключи, ни имена, ни контакты не записываются. Снимки не предназначены для семантического анализа: после удаления текста часть текстовых противоречий воспроизвести нельзя. Ошибка записи снимка не маскирует исходную ошибку.

Сохранённый обезличенный пример неизвестного ID включён в fixtures и воспроизводится тестом; отдельно проверено повторное воспроизведение ошибочной ссылки в descriptor_details нормализованного документа.

## Лимит, XP и сохранение

В проекте учёт расхода реализован дневными generation_events; отдельного списания XP в этой цепочке нет. Невалидный план или неудачный DOCX не вызывает запись в БД. Две неудачные попытки и следующая удачная дают ровно один вызов сохранения. Ошибка атомарного RPC не запускает запасное неатомарное создание материала.

Путь сохранения использует `SupabaseService.save_lesson_plan` и подготовленную ранее миграцию `004_atomic_lesson_plan.sql`: создание урока, событие лимита и материал должны коммититься одной транзакцией. Миграция **не применялась**, production не изменялся. Если RPC ещё отсутствует, сохранение завершится понятной ошибкой о необходимости миграции вместо небезопасного fallback. Проверки БД выполнены с mock-клиентом; реальная транзакция PostgreSQL в этой среде не запускалась.
