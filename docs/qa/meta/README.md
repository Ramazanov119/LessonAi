# Проверка исправлений META College

Результат: тестовые планы `lesson_meta_ru.docx` и `lesson_meta_kk.docx` содержат дату
09.10.2026 ж./г., семь этапов общей продолжительностью 70 минут и пять предметных
заданий с оцениванием на 100 баллов. Данные, из которых созданы документы,
находятся в соответствующих JSON-файлах. Использованы фиктивные данные.

## Причины ошибок

В исходном META-шаблоне поле даты содержало `{data} ж./г.`. Форма и повторный
экспорт передавали выбранную/сохранённую дату как `date`, а `_meta_template_fields`
формировал `data` из AI-ответа. Поэтому выбранная дата не имела приоритета над
сгенерированной датой в фактической ячейке. В проверенном исходном шаблоне дата
28.06.2024 не захардкожена. Без конкретного прежнего AI-ответа нельзя подтвердить,
откуда взялось именно это значение, но механизм подмены даты устранён.

В конфигурации META уже было 70 минут. В шаблоне были статические значения
5 + 5 + 20 + 20 + 5 + 2 + 3 = 60 минут. Генератор не подставлял время в эти ячейки.
Кроме того, `create_lesson` перезаписывал правильный запрос поурочного плана
запросом лекции, который не содержал инструкции о продолжительности.

Таблица оценивания была настоящей Word-таблицей с шестью демонстрационными
заданиями, пустыми критериями и дескрипторами. Экспорт не заполнял её строками.

## Реализация

- Исправлен существующий AI-запрос, для META в него добавлены `lesson_stages`
  и `assessment_items`. Дополнительный AI-запрос не выполняется.
- Конфигурация META определяет 70 минут. Названия, содержание и минуты этапов
  сохраняются в том же JSON материала, который уже хранится в Supabase.
- Распределение времени учитывает тип урока через промпт. При несовпадении суммы
  применяется пропорциональное целочисленное распределение с минимумом одной
  минуты на этап; порядок и содержание этапов не меняются.
- Каждый оцениваемый `task_name` должен дословно присутствовать в указанном этапе.
  Критерии и дескрипторы должны быть непустыми и содержать предметные термины
  этого этапа. Это структурная и лексическая проверка, а не доказательство полной
  педагогической корректности задания.
- Уровни Блума проверяются по выбранному языку. Баллы — целые неотрицательные
  числа. Если сумма отличается от 100, баллы нормализуются методом наибольших
  остатков; одновременно пересчитываются отдельные баллы дескрипторов.
- Существующие строки этапов и оценивания заменяются динамическими строками
  на основе копий оригинальных ячеек. Таблицы не дублируются. Сохранены шрифты,
  ширины столбцов и границы. Длинный текст переносится, точная высота строк снята.
- Заголовки таблицы оценивания локализованы на русский, казахский и английский.
  Оригинальная двуязычная оболочка META-шаблона сохранена.
- Выбранная или сохранённая дата передаётся программно во все алиасы даты;
  при отсутствии используется текущая дата Asia/Almaty. META-плейсхолдер заменён
  на `{{lesson_date}}` с единственным суффиксом `ж./г.`. Даты нормативных
  документов не заменяются. Поддержаны плейсхолдеры, разбитые на несколько runs,
  в таблицах, обычном тексте и существующих колонтитулах.
- Неизменённые части DOCX-пакета сохранены побайтно: стили, нумерация, рисунки,
  настройки, отношения и колонтитулы без заменяемых значений.

## Проверки

Команда:

```bash
PYTHONPYCACHEPREFIX=/private/tmp/lessonai-pycache .venv/bin/python -m unittest discover -s tests -q
```

Результат: 32 теста успешно. Дополнительно прошли компиляция Python и
`git diff --check`. Тесты проверяют содержимое DOCX, даты, суммы и дескрипторы,
отказ при несвязанных заданиях/критериях, динамические количества строк,
70-минутные планы лекции/практики/лабораторной, совпадение предпросмотра и Word,
сохранение JSON и метаданных через mock Supabase, целостность шаблона и настройки
остальных колледжей. Платные AI-запросы и обращения к production не выполнялись.

Визуальная проверка: через локальный Quick Look проверены первая часть документа
и отдельно таблицы оценивания на русском и казахском: текст переносится,
сумма 100 видна, казахские символы отображаются. Полная постраничная проверка
в Word/LibreOffice не завершена: у пакетного рендерера нет `pdf2image`,
LibreOffice не установлен, ввод пути через UI Word работал некорректно.
Узкий столбец дескрипторов сохранён как в оригинале, поэтому длинные слова
могут переноситься на несколько строк.

Повторно создать образцы без AI и Supabase:

```bash
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python tests/generate_meta_samples.py
```
