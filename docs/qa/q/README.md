## Уведомление

Конфигурация — `config/releases.py`: `release_id`, `enabled`,
`duration_seconds`, заголовки и тексты на русском/казахском.
Версия — `release_2026_10_meta_q`, время — 15 секунд. Включена после проверок
анонсируемых функций META и Q.

Уведомление вызывается только на главной странице после авторизации и
представляет собой небольшой встроенный блок, без модального окна или
перекрытия основных элементов. Есть кнопка закрытия.

Используется локальный custom component Streamlit v1, совместимый с установленным
Streamlit 1.50.0. JS `setTimeout` отсчитывает 15 секунд от фактического появления.
Компонент подтверждает появление серверу; Python использует монотонный таймер
как дополнительную защиту. Rerun не сбрасывает браузерный таймер. После скрытия
высота iframe становится нулевой, а сервер удаляет компонент. Отправляются
конечные события показа/закрытия; `sleep` и цикл перерисовки не используются.
Обработчики уведомления не вызывают генерацию материалов.

Факт показа сохраняется через `auth.update_user` в метаданных текущего аккаунта:
`lessonai_seen_releases`. До показа читается серверная версия метаданных;
отметка записывается перед выдачей компонента. Повторная сессия/другое устройство
не показывают уже отмеченную версию. Новая версия имеет новый `release_id`.
Изменяется только этот ключ метаданных, без обновления профиля, XP или тарифов.
При ошибке сохранения уведомление не показывается с ложной отметкой.

SQL-миграция, новая таблица, service role и новые права не требуются.
Используется штатный [API метаданных Supabase](https://supabase.com/docs/reference/python/auth-updateuser).

В текущем проекте отдельного переключателя языка интерфейса нет: UI русскоязычный.
Уведомление учитывает `ui_language`, `interface_language` или `language` в
сессии/метаданных аккаунта; при отсутствии предпочтения используется русский.
Язык отдельного учебного документа не назначается языком всей платформы.

## Проверки

- 61 Python-тест прошёл, включая прежние META-проверки и новые Q/уведомления.
- 8 браузерных сценариев прошли в headless Chrome на локальном стенде с
  фиктивными аккаунтами и хранилищем в памяти: показ и доступность формы,
  реальное исчезновение через 15 секунд, отсутствие повторения при reload,
  новая версия, ручное закрытие, переход между разделами, казахский мобильный
  вид 390 px и новая браузерная сессия с сохранённым состоянием аккаунта.
- В последнем запуске исчезновение измерено через 15 078 мс после появления.
- Счётчик фиктивных генераций оставался 0 при показе и закрытии уведомления.
- Ширина содержимого компонента на мобильном не превышает viewport.
- `compileall` и `git diff --check` прошли.
- Через Quick Look проверены образцы Q и отдельно новая строка на обоих языках.
  Полная постраничная проверка в Word/LibreOffice не выполнялась.
- Платные AI-запросы и обращения к production Supabase не выполнялись.
